# Technique stack

Demoscene resources were read as *mathematics*, not as look:

- thebookofshaders.com — domain warp, palettes (restrained)
- jamie-wong / 9bitscience / hg_sdf — signed distance as a query
- L-systems, splines — core grammars
- Voronoi — stitch ground, never cell-colour demos
- 2:1 isometric (`src/engine/iso.js`) — Scenes 3 and 5, furniture and strapwork halls
- Occupancy-steered growth — Scene 0 plants rooted on the rim, extend from the tip

The picture is historical ornament. The implementation may use demo maths.

See `/workspace/docs/SCENES.md` for the scene bible (well colours, Scene 4 KJV 1611, Scene 6 firmament chart).

Future (not yet): isometric dancers in period dress on the floors of scenes 3 and 5 — `docs/FUTURE.md`.
