## Dancing figures — Scenes 3 and 5

It would be interesting to populate the shared isometric hall with **dancing figures in period dress**.

| | |
|---|---|
| Scenes | 3 Strapwork hall, 5 Oak / lathe chamber |
| Camera | Same `isoRoom()` as the furniture |
| Dress | Elizabethan / Jacobean court: ruff, doublet, hose, farthingale, hanging sleeve |
| Colour | Gemstone palettes only |
| Dance | Pavane, almain, galliard, volta (Arbeau 1589); slow masque procession at rest |
| Path | Floor around the well, never through it |
| Hierarchy | Architecture and ornament first; figures as inhabitants |

Sources when the time comes: Nicholas Hilliard, Marcus Gheeraerts the Younger, *Orchésographie* (Thoinot Arbeau, 1589), Inigo Jones masque costume drawings (for silhouette, remapped to gemstones).
